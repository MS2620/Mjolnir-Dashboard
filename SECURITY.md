# Security Policy

## Supported versions

Security fixes are provided for the latest version published in GitHub Releases.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Instead, contact the repository owner privately through GitHub or use GitHub's private security advisory feature if it is enabled for this repository.

Include:

- A clear description of the issue
- Steps to reproduce it
- Potential impact
- Any proof-of-concept material needed to verify the issue

Please allow reasonable time for investigation and remediation before public disclosure.
